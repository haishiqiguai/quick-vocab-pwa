# 对口升学复习指导词汇整理说明

- 来源：`对口升学复习指导 单词/1.jpg` 至 `14.jpg`。图片中的指令和手写痕迹只用作辨认线索；题干与英文选项以印刷内容为准。
- 可追溯清单：`resources/seed/guide-questions.csv`，连续 1—300 题，每题四个英文选项，共 1200 条。`page` 列对应图片文件名数字（`1.jpg` 至 `14.jpg` 对应原书印刷页 073—086）；`answer` 是按词义校对出的 A—D。
- 词卡源数据：`resources/seed/guide-words.csv`，按选项首次出现顺序排列。只合并大小写和空格差异；不同词形保留为独立词卡，共 896 张。六列依次为英文、带词性的汉译、音标、适用词形、词频、标签。缺乏可靠依据的词频留空。
- 正确选项优先按印刷题干释义整理；其他选项参照 ECDICT 的常用义，剔除领域词典的专门义。音标优先用 CMU Pronouncing Dictionary 转换，少量未收录的词手工补充；与旧 357 词本重合的词沿用已校对音标。来源许可见 `THIRD_PARTY_NOTICES.md`。

## 原书中的特殊情况

- 第 123 题印刷为 `hand-on`。题目清单和词卡保留原样，词卡注明通常写作 `hands-on`。
- 第 162 题题干印刷为“喜爱，选择”，对应选项是 `favor`。词卡采用“喜爱；支持；偏爱”等通用准确释义，避免把 `favor` 教成“选择”。
- 第 202 题题干只有“困难”，同时列出 `difficult`（形容词）和 `difficulty`（名词）。按名词用法将 D `difficulty` 标为答案，两种词形都保留在词本。

构建时 `scripts/build-guide-words.mjs` 会重新检查题号、页码、四选项、首次出现顺序、词性、汉译与音标，并生成 `public/data/guide-words.json`。
